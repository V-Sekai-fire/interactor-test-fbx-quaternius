# interactor-test-fbx-quaternius

Low-poly character and prop packs in FBX, each with reference OBJ geometry and a record of its source and licence, for import tests.

## What it is for

An importer test reads each FBX file and compares what it gets with the OBJ beside it, including chosen animation frames for the characters. A JSON record per pack gives its title, author, source and licence.

## Build and run

There is nothing to build; the files are read as they are.

## Licence

CC0 1.0, as each pack's JSON record states. The repository adds none of its own.
